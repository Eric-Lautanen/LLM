novice:
  The missing information is a single, obvious field (e.g. "what language?").
  User will recognize the gap immediately when asked.
  Single-turn, one missing piece.

intermediate:
  Multiple missing pieces, or the gap requires domain knowledge to identify.
  User might not realize something is missing.
  Requires asking 1-2 follow-ups.

expert:
  Contradictory or conflicting requirements that require re-framing.
  The model must identify inconsistency, not just missing info.
  Requires proposing a resolution.

frontier:
  Implicit assumptions that contradict the stated goal — the user hasn't noticed.
  Or: requirements are deliberately underspecified and the model must negotiate scope.
  Or: political/organizational constraints embedded in technical requirements.
