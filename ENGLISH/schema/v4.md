# Schema v4 — Foundation layer taxonomy

## Axes

- Axis 1: Cognitive task type (33 categories, see category-specific schema files)
- Axis 2: Interaction format (single_turn, multi_turn, lecture, code_review, rubber_duck, adversarial, tool_call)
- Axis 3: Difficulty (novice, intermediate, expert, frontier)
- Axis 4: Abstraction level (metacognitive, procedural, pattern_recognition, declarative)

## concept_id derivation

concept_id = sha256(task_type + ":" + subtype + ":" + difficulty + ":" + abstraction_level + ":" + scenario_seed)

Where scenario_seed is drawn from the per-category topic registry (schema/<category>/topics.json). See §3.1, §14.5.
